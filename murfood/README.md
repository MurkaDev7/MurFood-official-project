# MurFood-official-project
1. MurFood - это сайт с едой (ресторан) и это просто как тест проект там не будет функции доставки и т.д

2. название взято как пример ведь  автор не сценарист и вообще не может нормальное имя придумать

3. сайт может быть не доделан на данный момент

4. картинки взяты из интеренета

5. картинка где нарисован логотип MurFood это ИИ

6. в коде не используется ИИ (ИИ был использован только в картинке)

7. если у вас не показываются картинки тогда зайдите в папку MurFood -> src -> файлы с jpe потом измените их на jpeg и у вас будут работать картинки


# Translate


1. MurFood is a food-related website (for a restaurant); it is simply a test project, so features like delivery won't be included

2. The name is just an example, as the creator isn't a writer and couldn't come up with a proper name

3. The site may be unfinished at the moment

4. The images are sourced from the internet

5. The image featuring the MurFood logo was generated by AI

6. No AI is used in the code itself (AI was used only for the image)

7. If the images aren't displaying, go to the `MurFood -> src` folder, find the files with the `.jpe` extension, rename them to `.jpeg`, and the images will work.
